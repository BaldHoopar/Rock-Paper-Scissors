# Rock-Paper-Scissors
This repository was created to practice JavaScript. This exercise is under Odin Project's JavaScript Basic section.

## getComputerChoice()
This was created for the computer to generate a random number from 0-8.
- 0-2 == "Rock"
- 3-5 == "Paper"
- 6-8 == "Scissors"

## getHumanChoice()
This function prompted the user for text of either "Rock", "Paper", or "Scissors". It was then converted to lowercase to make the response case insensitive.

## playRound()
This function compared the result from the getComputerChoice() function and the getHumanChoice() function to. It determined who was the winner based on conditional statements.

## playGame()
This function initialized the game. It contained 5 rounds after each round awarded a score to whoever won the round between the computer and the human.
It then compare who had more wins after the 5 rounds and printed out the winner.
